# laplacian-smooth

JOSM plugin implementing Laplacian line smoothing algorithm.

## Description
Details: [OSM Wiki](https://wiki.openstreetmap.org/wiki/JOSM/Plugins/LaplacianSmooth)

## Installation

1. Download `laplacian-smooth.jar` from Releases.
2. Copy it to your JOSM plugins folder.
3. Restart JOSM.
4. The tool will appear in the **Mytools** menu as **Laplacian smoothing**.

## Usage

1. Select one or more ways.
2. Go to **Mytools → Laplacian smoothing** or press `Ctrl+Shift+L`.
3. Configure parameters (Iterations, Strength) and click **Apply**.
