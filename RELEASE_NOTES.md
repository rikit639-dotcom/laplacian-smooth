### Release Notes: v4.8.0

**English**
* Added customizable corner angle threshold with dynamic visual preview.
* Corrected corner detection logic to match visible map geometry.
* Improved dialog layout with adaptive window sizing and uniform button widths.
* Optimized translations across all languages to eliminate text clipping.

**Russian**
* Добавлен настраиваемый порог сохранения острых углов с динамической визуализацией.
* Исправлен алгоритм определения углов в соответствии с видимой геометрией на карте.
* Улучшена компоновка окна: адаптивный размер и единая ширина кнопок.
* Оптимизирована локализация для исключения обрезки текста во всех языках.
